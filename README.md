# FastAPI Sample Application

A lightweight, high-performance RESTful API built with **FastAPI** and **Python**.

## Features

* Fast and modern asynchronous API endpoints.
* Automatic interactive API documentation (Swagger UI & ReDoc).
* Request parameter validation and type hints.

## Prerequisites

* Python 3.8+ (Python 3.11 or 3.12 recommended)
* `pip` package manager
